# Project Brief: Onyx: Habit Tracker & Focus

## Overview

Onyx is a production-ready mobile application designed for Gen Z students, focusing on habit tracking, focus (Pomodoro), and building streaks with a "Dark Mode / Neon" aesthetic.

## Core Requirements

- **Habit Tracking:** Users can add habits, track streaks, and visualize progress.
- **Focus Mode:** A Pomodoro timer to help students stay productive.
- **Social Integration:** "Flex" mode to share habit streaks on social media (e.g., Instagram Stories).
- **Gamification:** Streak-based rewards and progress bars.
- **Monetization:** Freemium model with a Pro version (unlimited habits, no ads, pro widgets).
- **Multi-language Support:** English, Turkish, Spanish, German, Italian, Russian, Chinese.

## Goals

- Provide a visually striking and engaging tool for habit formation.
- Achieve sustainable revenue through subscriptions and ads.
- Ensure cross-platform compatibility (Android and iOS).
- Offer offline-first functionality with cloud synchronization.
